What I do

I like the whole arc of a data project: taking messy, unreliable data, cleaning it up, figuring out what's actually going on, and explaining it clearly.

Right now I'm a Customer Operations Analyst at Inland Management, where I keep 10,000+ Salesforce lead records clean and reliable, and turn operational trends into narratives that senior leadership actually uses to make decisions. Before that, at Spirit Electronics, I built Power BI dashboards that saved the team 5 to 8 hours of manual reporting a week and helped shape a content strategy that lifted engagement by 15%.

I have my M.S. in Business Analytics from Grand Canyon University with a 4.0 GPA, and I used that program to go deeper technically. My capstone segmented 93,000+ guest transactions using K-Means clustering and built a Random Forest model to predict spend.

On my own time, I keep building full cloud pipelines end to end. One project pulls stock data through Python into Azure SQL, transforms it with layered SQL, and surfaces it in a Power BI dashboard with custom DAX measures, including tracking down a filter context bug that was quietly returning the wrong answer under certain slicer selections. Another moves raw data through dbt Cloud into BigQuery fact and dimension tables, where I caught two real data integrity issues before they reached the dashboard.

I love the whole process, top to bottom. Cleaning the data, building the pipeline, modeling it, visualizing it, and explaining what it means. Looking for data analyst roles where I get to keep working that whole chain, from raw data to a decision someone actually makes.

Projects

Guest Segmentation Capstone

  • Python
  • scikit-learn
  • K-Means
  • Random Forest

Applied the CRISP-DM framework to 93,000+ guest transaction records to segment a retail guest base by purchasing behavior, enabling personalized marketing over broad, one-size-fits-all campaigns. Engineered 7 behavioral features and applied K-Means clustering to identify two guest segments, validating results through holdout testing, 5-fold cross-validation, and bootstrap resampling.

Found that loyal guests, just 3% of the base, spent nearly 2x more on average (p < .001). Built a tuned Random Forest model (60.1% R² on holdout) to predict guest-level spend, and designed a full deployment plan with batch scoring architecture, a governance framework, and a cost-benefit case projecting positive ROI within year one.

Market Volatility Pipeline

  • Python
  • Azure SQL
  • SQL
  • Power BI
  • DAX

End to end cloud pipeline analyzing stock price volatility across five sectors. Python pulls daily price data for 15 stocks and loads it into Azure SQL Database, then layered SQL views calculate daily returns and 30-day rolling volatility using window functions. Power BI connects directly to Azure SQL, using custom DAX measures for year-to-date return and sector-level comparison.

Diagnosed and fixed a filter context bug where headline KPI measures were recalculating based on ticker-level slicer selections instead of staying locked to the full market view, resolved with CALCULATE and REMOVEFILTERS. Also traced a data quality issue back through the mart and staging layers to a bad API response, confirming the pipeline logic itself was sound.

Fintech Analytics Pipeline

  • Python
  • SQL
  • dbt Cloud
  • BigQuery
  • Power BI

Production-style analytics pipeline using Python, SQL, and dbt Cloud, transforming raw data through staging and mart layers into fact and dimension tables in BigQuery, tested and documented via schema.yml. Rebuilt the Power BI layer after diagnosing two data model issues, an unfiltered spend measure and a collapsed date grain, that were inflating and distorting key metrics.

Engineered a customer risk model using SQL to segment 500 users by credit score and overdraft behavior, surfacing a counterintuitive finding: high-risk users hold the highest average account balances, but also average 2.29 overdrafts, pointing to overdraft history rather than balance as the likely driver of risk.
